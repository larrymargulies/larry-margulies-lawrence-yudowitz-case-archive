# Larry Margulies / Lawrence Yudowitz — Public Investigative Case Records Archive

This public archive provides an organized investigative index to source records concerning Larry Margulies / Lawrence Yudowitz. It is intended to facilitate genuine review by citizens and, where relevant, law-enforcement personnel, professional investigators, attorneys, journalists, researchers, and oversight bodies.

The archive currently preserves 16 source records:

- Philippines — 4 records
- Florida / Aventura — 7 records
- State OIG — 5 records

## Purpose

This repository is maintained as a neutral, evidence-first public investigative case-record archive.

Its purpose is to preserve source materials, facilitate source verification and chronological review, identify relationships among records, and assist legitimate investigation of unresolved questions.

It is not presented as a commercial brand, course, capstone, podcast, promotional project, or entertainment collection.

## Evidentiary status

Complaints remain complaints. Allegations remain allegations unless independently established. Witness statements remain attributed statements. Affidavits remain affidavits. Official records retain their actual provenance.

Publication does not by itself establish guilt, prove a claim, establish probable cause, determine authenticity or admissibility, constitute a judicial finding, require prosecution, or represent endorsement by any law-enforcement agency.

Original historical documents and filenames should be preserved unchanged where necessary for provenance. Documented source material, attributed statements, allegations, analytical inferences, and unresolved or missing information must remain clearly distinguished.

## Principal preservation repository

The preserved source records are publicly available through Zenodo:

**DOI:** https://doi.org/10.5281/zenodo.22884193

Zenodo serves as the principal preservation repository. This GitHub repository and its GitHub Pages site provide an additional public investigative index and access point.

## Investigator / Law-Enforcement Review

Records should be reviewed, where applicable, according to:

1. Complaints and supplemental complaints
2. Affidavits and sworn statements
3. Official correspondence and agency records
4. Exhibits and supporting source records
5. Publicly releasable witness/source material
6. Source-supported chronology
7. Preservation and integrity information
8. Unresolved evidentiary gaps

Where available, individual records should identify the document date, originating source, jurisdiction, document type, complaint/case/report number, exhibit number, provenance, version status, related records, and preservation location.
