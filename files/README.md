# Preserved source records

This directory contains original public case-record files preserved in the **Larry Margulies / Lawrence Yudowitz — Public Investigative Case Records Archive**.

Original source documents and historical filenames are retained for provenance. Complaints remain complaints; allegations remain allegations unless independently established; affidavits remain affidavits; and attributed statements remain attributed statements.

Publication does not independently authenticate a document, establish the truth of an allegation, determine admissibility, establish guilt or probable cause, require investigative or prosecutorial action, or represent endorsement by any law-enforcement agency, court, or government body.
